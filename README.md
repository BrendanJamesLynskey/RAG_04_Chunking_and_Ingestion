# RAG 04 — Chunking & Ingestion

Deep-dive into the document ingestion layer: chunking philosophies and strategies (fixed, semantic, structural, contextual), recursive character splitting edge cases, layout-aware parsing tools (Unstructured, MinerU, LlamaParse, Docling), vision-based ColPali document parsing, metadata enrichment, deduplication techniques (MinHash, SimHash), and incremental ingestion pipeline design with embedding refresh.
